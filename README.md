# airline-microservice
1. Create City
2. Create Airport for the City
3. Create Airline for the Airport
4. Create Aircraft for the Airline 
5. Create Cabin Class for the Aircraft
6. Create Seat Map for the Cabin Class (Will create Seats for the Seat Map)
7. Create Flight for the Airline and Aircraft
8. Create Flight Schedule for the Flight (Will create Flight Instances for the Flight Schedule, 
send "flight_instance_created" and creates Flight Instance Cabin and Seat Instance for the Flight Instance Cabin)
9. Search for Flights based on origin, destination and date
10. Book a Flight Instance for a Passenger (Will create Booking and Booking Instance for the Flight Instance, send "booking_created" and creates Booking Instance Cabin and Seat for the Booking Instance Cabin)
